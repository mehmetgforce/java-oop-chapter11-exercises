# Java OOP - Chapter 11 Exercises (Inheritance & Polymorphism)

Bu proje, Y. Daniel Liang'ın *Introduction to Java Programming and Data Structures* kitabının 11. bölümüne ait nesne yönelimli programlama (OOP) alıştırmalarını içermektedir.

## 🚀 Proje İçeriği ve Uygulanan Konular
* **Kalıtım (Inheritance):** GeometricObject - Triangle, Person - Student/Employee/Faculty/Staff hiyerarşik sınıfları.
* **Method Overriding (Ezme) & Çok Biçimlilik (Polymorphism):** Account, SavingsAccount ve CheckingAccount sınıfları ile farklı kurallara sahip para çekme mekanizmaları.
* **ArrayList Entegrasyonu:** Standart diziler yerine dinamik `ArrayList` yapıları kullanan Course, MaxArrayList ve Shuffle algoritmaları.
* **Özel Veri Yapıları:** `ArrayList` sınıfından kalıtım alınarak (`extends`) geliştirilen LIFO mantıklı **MyStack** yığın sınıfı.
* **Matris Analizleri:** 2 boyutlu matrisler üzerinde rastgele 0-1 üretip en çok 1 barındıran satır ve sütun indislerini bulan dinamik algoritma (Exercise 11.9).
